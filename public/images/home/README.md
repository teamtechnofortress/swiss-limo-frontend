# Homepage images

Place the main homepage photograph at:

`public/images/home/hero.jpg`

Recommended specifications:

- Landscape image, at least `2400 × 1350` pixels (16:9)
- Optimised JPG or WebP, ideally below 700 KB
- Keep the primary vehicle or scenery toward the right side; the left side is reserved for the hero text
- Avoid baked-in text or logos—the page adds its own overlay and content

The frontend serves this asset at `/images/home/hero.jpg`. Replacing the file updates the hero image without changing code.
